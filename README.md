## Overview
Love Maths is a lightweight, static website built to present math problems and visualisations in an engaging way. It's intended as a portfolio piece demonstrating interactive UI, modular CSS, and vanilla JavaScript.

## Features
- Interactive problem examples and solutions
- Responsive layout with custom styles
- Lightweight, dependency-free frontend

## Technologies Used
- **Languages:** HTML, CSS, JavaScript
- **Tools:** Git, any static file server or local filesystem

## How to Use

### Local Setup
```bash
git clone https://github.com/your-username/love-maths.git
cd love-maths
# Option 1: Open directly in your browser
open index.html

# Option 2: Serve locally (recommended for fetches or routing)
python3 -m http.server 8000
# Then open http://localhost:8000 in your browser
```
